Know how much is left.

Your Claude and Codex plan limits in the menu bar: what's used, when it resets, and whether your pace lasts until then.

Free. macOS 26 or later.

Always in view.

Two rings and two numbers in the menu bar: the 5-hour session on top, the week below. You see a limit coming before you hit it.

Pace, not just percent.

60% used means little without the clock. Tokei compares your usage to an even spread over the window and tells you if it lasts until reset, or when it runs out.

Quiet by design.

It refreshes every 5 minutes while Claude Code or Codex is working and every 15 when idle, and pauses while the Mac sleeps or is locked. No Keychain prompts in the background.

The little things.

  • Reset alerts

    A notification the moment a session or weekly limit resets.

  • Service status

    Shows when Claude Code or Codex has an outage, so you know it isn't you.

  • 7-day history

    A small line under each limit shows how your usage moved this week.

  • Per-model limits

    Separate weekly limits, like Opus or Fable, get their own row.

    Count up as you use your plan, or count down what's left.

    New versions install from the app, signed and verified.

Install.

Homebrew

brew install --cask wormadev/tap/tokei

Download

Tokei isn't notarized by Apple yet, so macOS asks once:

  1. Open the DMG and drag Tokei to Applications.
  2. Open Tokei. macOS says it can't check it for malicious software.
  3. Go to System Settings > Privacy & Security and click Open Anyway.
Download Tokei.dmg

Then

Sign in to Claude Code or Codex once, if you haven't. Tokei reads the sign-in they already saved and shows up in the menu bar.

Questions.

Where do my tokens go?

Only to the provider they belong to: your Claude token to api.anthropic.com, your Codex token to chatgpt.com. Tokei has no server, no account and no analytics.

Will it log me out of Claude Code or Codex?

No. Tokei never refreshes their tokens: the refresh token belongs to the CLI, and rotating it would sign the CLI out. When a token expires, Tokei asks you to run claude or codex again.

Why does it ask for Keychain access?

Claude Code keeps its sign-in in the Keychain. Tokei reads it only after you click Connect in Settings, and background refreshes never trigger a prompt. If the sign-in file in ~/.claude is current, no Keychain access is needed.

Which plans does it work with?

Claude plans that come with Claude Code (Pro, Max), and ChatGPT plans that include Codex.

Which Macs does it run on?

Any Mac with macOS 26 or later.
