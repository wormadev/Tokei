The panel's Fix button asks the CLI to renew the sign-in, and Open Terminal runs the CLI when that isn't enough. Opt-in "Renew expired sign-ins" does this by itself.
- Limits past their reset time show as unknown instead of the old number.
- Plan names follow Anthropic's rename: Max 20x is now Ultra, Max 5x is now Max. Ultra has no 5-hour limit, so the menu bar shows the weekly number.
- The app icon is blue in dark mode too.
- Check for Updates is in the panel's gear menu. When an update is found in the background, the panel shows "Update to …" instead of a window that opens behind your other apps.
